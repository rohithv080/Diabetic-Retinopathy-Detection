Academic Note for Evaluators

Unlike standard convolutional neural networks with static local receptive fields, the Swin Transformer uses shifted local windows (W-MSA & SW-MSA) to capture both microaneurysms and global macula context. Visual interpretability is derived via Grad-CAM targeted at the final normalization layer (layers[-1].blocks[-1].norm1).

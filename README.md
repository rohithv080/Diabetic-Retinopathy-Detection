# Diabetic Retinopathy Detection using Swin Transformer

This project builds upon the base paper by upgrading the Vision Transformer architecture to a hierarchical Swin Transformer.

## Project Structure

- `data/raw/`: Place your raw dataset here (e.g., APTOS 2019 dataset).
- `data/processed/`: Processed images will be saved here.
- `src/`: Contains the source code for data loading, modeling, training, and evaluation.
- `notebooks/`: Jupyter notebooks for EDA and quick experiments.

## Setup

1. Place your dataset inside the `data/raw/` directory.
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```
